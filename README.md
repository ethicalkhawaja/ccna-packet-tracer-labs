# CCNA Packet Tracer Labs

This repository contains CCNA-level networking labs created using Cisco Packet Tracer.

The labs cover core networking concepts including VLANs, routing, OSPF, DHCP, NAT, ACLs, and enterprise network design.

## Labs Included

- 01 VLANs & Inter-VLAN Routing
- 02 Static Routing
- 03 OSPF Single Area
- 04 DHCP & NAT
- 05 ACL Security
- 06 Enterprise Network Design
- 07-Etherchannel-LACP

## Tools Used
- Cisco Packet Tracer

## Purpose
To build practical networking skills and prepare for IT and networking roles.
