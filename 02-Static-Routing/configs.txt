# Static Routing Lab

## Overview

This project demonstrates Static Routing between three routers connecting three different LANs.

### Topology

LAN 1
Network: 192.168.1.0/24
Gateway: 192.168.1.254

LAN 2
Network: 192.168.2.0/24
Gateway: 192.168.2.254

LAN 3
Network: 192.168.3.0/24
Gateway: 192.168.3.254

WAN Links

R1 ↔ R2 : 10.0.12.0/30
R1: 10.0.12.1
R2: 10.0.12.2

R2 ↔ R3 : 10.0.23.0/30
R2: 10.0.23.1
R3: 10.0.23.2

## Features

- Static Routing
- Multi-LAN Connectivity
- End-to-End Ping Testing
- Cisco Packet Tracer Lab
- CCNA Routing Fundamentals

## Configuration

### R1

```cisco
hostname R1

interface g0/1
 ip address 192.168.1.254 255.255.255.0
 no shutdown

interface g0/0
 ip address 10.0.12.1 255.255.255.252
 no shutdown

ip route 192.168.2.0 255.255.255.0 10.0.12.2
ip route 192.168.3.0 255.255.255.0 10.0.12.2
```

### R2
hostname R2

interface g0/1
 ip address 192.168.2.254 255.255.255.0
 no shutdown

interface g0/0
 ip address 10.0.12.2 255.255.255.252
 no shutdown

interface g0/2
 ip address 10.0.23.1 255.255.255.252
 no shutdown

ip route 192.168.1.0 255.255.255.0 10.0.12.1
ip route 192.168.3.0 255.255.255.0 10.0.23.2
```

### R3
hostname R3

interface g0/0
 ip address 192.168.3.254 255.255.255.0
 no shutdown

interface g0/2
 ip address 10.0.23.2 255.255.255.252
 no shutdown

ip route 192.168.1.0 255.255.255.0 10.0.23.1
ip route 192.168.2.0 255.255.255.0 10.0.23.1
```
